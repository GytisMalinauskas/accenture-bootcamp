# AGENTS.md — Day 11–12 Local RAG Capstone

## Working Directory & Environment
- Run all commands from `day11-12/`.
- Python package manager: `uv` (`uv run python <script>.py`).
- Never commit `.env`, `.venv/`, or `chroma_db/`.

## Ground Rules (from Capstone Brief)
1. **Local models only:** Never use cloud-tagged Ollama models (tags with `cloud` or cloud badges). All pipeline inference and embeddings must run locally via Ollama (`http://localhost:11434/v1`).
2. **Numbers come from files:** Every metric reported in `decision_log.md` or `README.md` must come directly from `benchmark_results.json` or `pipeline_outputs.json`. Never invent or estimate numbers.
3. **Every chat call must set `reasoning_effort="none"`** (unless intentionally testing thinking) and pass the token limit via `config.TOKEN_LIMIT_PARAM`.
4. **Manual work stays manual:** Quality ratings (`quality_rating`, `rating_note`, `passed`) and `decision_log.md` are written/filled in by the developer, not generated by the assistant.
5. **One step at a time:** Build, run, verify, and commit each module before moving to the next.

## Scripts & Verification Checks
- **API & Context Check:** `uv run python test_api.py`
  - Verify output prints one sentence + `stop`, then run `ollama ps` and confirm `CONTEXT` is `8192`.
- **Exercise 1 (Benchmark):** `uv run python benchmark.py`
  - Verify `benchmark_results.json` has all model × prompt rows, no empty responses, and `finish_reason` recorded.
- **Exercise 2 (Ingest):** `uv run python ingest.py`
  - Verify `chroma_db/` is created, PDFs load cleanly, and `collection.count()` does not duplicate on re-run.
- **Exercise 2 (Retrieve):** `uv run python retrieve.py`
  - Verify cosine relevance scores are between `0` and `1` and metadata (`source`, `page`) is present.
- **Exercise 2 (Pipeline):** `uv run python pipeline.py`
  - Verify `pipeline_outputs.json` records all `test_questions.json` rows with non-empty answers and `finish_reason`.
